راهنمای راه‌اندازی (یک‌بار، حدود ۱۵ دقیقه)
=============================================
بعد از این، برنامه روی سرور رایگان گیت‌هاب اجرا می‌شود و هر حدود ۱۰ دقیقه پست‌های جدید کانال‌های مبدا را
در کانال شما منتشر می‌کند. کامپیوتر و VPN شما لازم نیست روشن باشد.


۱) ساختن ربات
-------------
- در تلگرام برود به @BotFather
- بنویسید: /newbot
- یک اسم و بعد یک یوزرنیم (باید به bot ختم شود) بدهید.
- یک «توکن» می‌دهد (چیزی شبیه 123456:ABC-DEF...). آن را کپی کنید. این توکن مثل رمز است؛ به کسی ندهید.

۲) ادمین کردن ربات در کانال @YOUR_CHANNEL
-----------------------------------
- کانال ← Administrators ← Add Administrator ← یوزرنیم ربات را جستجو و انتخاب کنید.
- دسترسی Post Messages باید روشن باشد. ذخیره کنید.

۳) آماده کردن تنظیمات
---------------------
- فایل config.example.json را با Notepad باز کنید.
- به جای PASTE_BOT_TOKEN_HERE توکن را بگذارید (داخل گیومه بماند).
- به جای source_channel_1 و source_channel_2 یوزرنیم کانال‌های مبدا را بنویسید (بدون @). هر تعداد خواستید.
- کل متن را کپی کنید (Ctrl+A و Ctrl+C) و Notepad را بدون ذخیره کردن ببندید (Don't Save).
  مهم: فایل را ذخیره نکنید تا توکن داخل فایل‌هایی که آپلود می‌شوند نماند.

۴) ساختن حساب و مخزن در گیت‌هاب
------------------------------
- به github.com بروید و حساب رایگان بسازید.
- بالا سمت راست + ← New repository
- اسم: مثلاً tg-sync
- حتماً Public را انتخاب کنید (برای اجرای نامحدود و رایگان). چیز محرمانه‌ای داخل آن نیست.
- Create repository

۵) آپلود فایل‌ها
----------------
- فایل zip را از حالت فشرده خارج کنید.
- در صفحه مخزن روی «uploading an existing file» بزنید.
- تمام فایل‌ها و پوشه‌های داخل پوشه را بکشید و رها کنید (repost.py ، پوشه .github و ...).
- پایین صفحه Commit changes
- اگر پوشه .github آپلود نشد (چون مخفی است): Add file ← Create new file ، در خانه اسم تایپ کنید
  .github/workflows/repost.yml و محتوای فایل repost.yml را در آن Paste کنید. همین کار را برای check.yml هم بکنید.

۶) گذاشتن تنظیمات به‌صورت محرمانه
---------------------------------
- مخزن ← Settings ← Secrets and variables ← Actions ← New repository secret
- Name:  CONFIG_JSON
- Secret: متنی که در مرحله ۳ کپی کردید (کل فایل با توکن و اسم کانال‌ها)
- Add secret

۷) بررسی و روشن کردن
--------------------
- تب Actions ← اگر دکمه‌ای برای فعال کردن (Enable) دید، بزنید.
- از لیست سمت چپ «check» ← Run workflow ← Run workflow
- بعد از یک دقیقه روی اجرای آن بزنید. اگر سبز شد و نوشته ALL GOOD یعنی همه‌چیز درست است.
  اگر قرمز شد، متن خطا را برای من بفرستید (توکن را نفرستید).
- بعد «repost» را باز کنید ← Run workflow. اولین اجرا فقط آخرین پست‌های فعلی را به‌عنوان «دیده‌شده» ثبت
  می‌کند و چیزی منتشر نمی‌کند. از آن به بعد هر پست جدید منتشر می‌شود.

نکته‌ها
-------
- گیت‌هاب زمان‌بندی را دقیق اجرا نمی‌کند و گاهی ۵ تا ۳۰ دقیقه دیر می‌شود.
- فیلتر تبلیغ: هر پستی که لینک سایت یا اپ داشته باشد (غیر از لینک تلگرام)، کلمه‌های بت و شرط‌بندی و
  کازینو و ... داشته باشد، یا لینک دعوت به کانال دیگر (t.me/+...) داشته باشد منتشر نمی‌شود.
  این فیلتر حدسی است و ۱۰۰٪ نیست؛ گاهی پست عادی رد می‌شود یا تبلیغ بدون لینک رد نمی‌شود.
  برای تنظیم: در همان تنظیمات (CONFIG_JSON) می‌توانید کلمه‌های تبلیغی خودتان را در extra_ad_keywords بگذارید، مثلاً ["کلمه۱", "کلمه۲"].
  اگر نمی‌خواهید پست‌های لینک‌دار رد شوند: "skip_posts_with_links": false
- ویدیوهای بزرگ‌تر از ۵۰ مگابایت، پیام صوتی، فایل و نظرسنجی کپی نمی‌شوند و آن پست رد می‌شود.
- اگر یک روز دیدید ربات کار نمی‌کند، در تب Actions دکمه Enable را بزنید (گیت‌هاب بعد از ۶۰ روز
  بی‌فعالیتی ممکن است زمان‌بندی را خاموش کند).
- برای عوض کردن تنظیمات: Secret به نام CONFIG_JSON را دوباره با متن جدید ذخیره کنید.
